# 이어받기 메모 (2026-10-25 기준)

다른 에이전트나 다음 세션이 바로 이어서 작업할 수 있게 지금 상태를 적는다. 새 작업을 끝내면 이 파일도 고친다.

## 프로젝트
- **Next Step**: 취업 준비생과 이직 준비생을 위한 공부 계획, 기록, 돌아보기 도구(여러 사용자).

- 인증: 구글 로그인 + 서버 세션(Spring Session JDBC, PostgreSQL 저장), CSRF는 쿠키 방식. JWT는 쓰지 않는다(`docs/deploy.md` 4장).

## 알아 둘 함정
- 테스트는 `main()`을 거치지 않아 시간대가 늦게 정해진다. 테스트 JVM은 `build.gradle.kts`에서 Asia/Seoul로 고정했다(`docs/troubleshooting/2026-10-25-ci-timezone.md`).
- Spring Session은 JPA가 아닌 순수 JDBC 트랜잭션 매니저를 써야 한다(멀티테넌시와 무한 반복, `docs/troubleshooting/2026-10-25-spring-session-login.md`).
- 운영 Compose는 필수 값이 비면 켜지지 않는다(`:?`). 로컬은 HTTPS가 아니라 Secure 쿠키 때문에 운영 설정으로 로그인 확인을 할 수 없다.
- 루트 콘솔 로그인은 패스키가 있는 Safari에서만 된다. 평소 AWS 작업은 액세스 포털의 `sangwoo` 계정으로 한다.

## 랜딩 리뉴얼 목업 (2026-10-25)
- `frontend/landing-preview.html`에 크림색과 라벤더를 사용한 별도 랜딩 시안을 만들었다. 로컬 Vite의 `/landing-preview.html`로 확인한다. 기존 랜딩에 적용하기 전 사용자 검토용이며, 시간표 칸 선택, 계획과 실제 전환, 시작 버튼 안내를 제공한다. PC와 모바일 배치를 지원한다.
- 랜딩 목업 배경은 사용자 요청에 따라 기존 서비스의 `#141414`와 보라색 빛으로 변경했다. 카드와 시간표도 어두운 배경에 맞춰 조정했다.
- 첫 화면 소품(별, 책, 달력, 커피)을 제거하고 스텝이만 남겼다. 느린 떠다니기와 호흡, 포인터에 따른 미세 기울기, 클릭과 터치 시 한 번 인사하는 움직임을 추가했다. 동작 줄이기 설정을 따르며, 화면 밖에서는 반복 움직임을 멈춘다.
- 스텝이 움직임을 다시 조정했다. 포인터 추적과 점프를 빼고 7.6초 주기의 작은 호흡과 클릭 시 1.8초의 가벼운 기울임으로 변경했다.
- 첫 화면 스텝이는 `stepe-rig.svg`로 부위를 분리한 SVG 목업으로 교체했다. 눈 깜빡임, 어깨 기준 손 흔들기, 몸 호흡을 각각 적용한다. 클릭하면 팔만 인사하며 동작 줄이기 설정을 따른다. SVG는 확정 PNG 시안을 기준으로 다시 그린 표현이라 원본의 질감과 차이가 있으며, 사용자 검토 후 본 랜딩 적용을 결정한다.
- SVG 재작화가 확정 PNG와 다른 캐릭터처럼 보인다는 사용자 피드백으로 첫 화면을 `mascot-wave-v2.png` 원본으로 복구했다. 현재는 원본 전체의 작은 호흡과 인사 움직임만 적용한다. 부위 애니메이션은 원본 디자인을 유지한 레이어 분리 후 다시 검토해야 한다.
- 2026-10-26: 원본 `mascot-wave-v2.png`를 그대로 보이는 SVG 이미지 레이어로 사용해 목업에서 눈을 가렸다 여는 깜박임과 클릭 시 몸 전체의 작은 인사 동작을 구현했다. 원본은 팔이 본체와 합쳐진 PNG라 팔만 독립 회전시키면 접합부가 어색해져 적용하지 않았다. 편집 가능한 원본 레이어를 확보하면 팔 단독 동작을 다시 검토한다. 모션 감소 설정과 화면 밖/탭 비활성 시 애니메이션 중지를 적용했다.
- 2026-10-26: 클릭해야 인사하는 동작이 어색하다는 피드백. 목업 첫 화면을 비대화형 자동 루프로 전환했다. 원본 PNG를 계속 재사용하며 천천히 기울고 숨 쉬는 움직임과 간헐적인 SVG 눈 깜박임을 CSS로 구현한다. 비디오는 만들지 않고 prefers-reduced-motion 및 화면 가시성에 맞춰 움직임을 제어한다.
- 2026-10-26 추가: 사용자가 몸이 앞으로 오는 듯한 인사가 부자연스럽다고 해 기울임/확대 동작을 제거했다. 현재 원본의 팔을 든 포즈를 유지하면서 미세한 상하 인사 움직임과 눈 깜박임을 반복한다. 클릭은 필요 없다.
- 2026-10-26 레이어 적용: 랜딩 목업 첫 화면에서 원본 PNG를 몸/팔로 분리해 조합하고, SVG 눈 레이어를 별도로 올렸다. 왼팔만 작은 각도로 자동 흔들고 눈을 6.2초 루프로 깜박인다. 몸 기울임은 없다. 양팔/몸 PNG와 눈 SVG는 `frontend/src/assets/illust/stepe-*-layer-v1.*`에 있다. 원본 `mascot-wave-v2.png`와 실제 앱 화면은 그대로다. 브라우저에서 기본 합성과 팔 위치를 확인했다. 사용자 확인 후 실제 랜딩에 적용할지 결정한다.

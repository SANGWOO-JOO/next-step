## 2. 목표 구조
```
최종 목표
 └ 월간 목표 ─────────── 월간 회고
    └ 주간 목표 → 주간 계획 ── 주간 일지 ── AI 주간 피드백
       └ 하루 목표(핵심 3개 + 추가 목록) → 시간 블록(계획) ↔ 실제 기록(실제) → 하루 기록 ── AI 하루 피드백
(1-4e부터 집중 세션 대신 "계획 vs 실제" 비교. 아래 1-4e 규칙 참고)
모든 목표/세션은 활동 분류(Category)를 가짐 → 시간 대시보드로 집계
```
- 아래 단계는 반드시 위 단계에 연결, 진행률 자동 집계
- 못 끝낸 하루 목표는 넘기기/재배치
- 주는 월요일 시작, 월에 걸친 주는 목요일이 속한 달(ISO)

규칙: CORE 하루 목표는 최대 3개(강제), EXTRA는 제한 없음.

1-2b에서 정한 규칙(2026-10-22):
- TimeBlock: 하루 목표의 날짜 안(최대 24:00까지)에서만, 같은 날 블록끼리 겹치지 않음. 하루 목표를 삭제하거나 다른 날로 넘기면 그 목표의 블록은 삭제(원래 날의 시간은 다른 날에 의미가 없으므로)
- FocusSession: 하루 목표 없이 분류만 골라 시작할 수 있음(공부 자료 찾기처럼 목표가 애매한 경우). 진행 중 세션은 1개
- 탭 이탈은 30초 이상일 때만 Interruption으로 기록

1-2b 집중 모드에서 정한 규칙(2026-10-23):
- 타이머는 서버의 startedAt 기준으로 계산. 실제 집중 시간 = 경과 − (DISTRACTION + BREAK 중단). STUDY_MATERIAL은 집중, 종류가 아직 정해지지 않은 열린 중단은 뺀다(타이머가 멈춤)
- 한 세션에 열린 중단은 1개, 중단끼리 겹치지 않음. 탭 이탈은 벗어난 시각·돌아온 시각을 보내 기록하고, 돌아오면 종류를 묻는다
- 종료 결과는 완료(COMPLETED)/더 하기(MORE)/딴짓(DISTRACTED) 3가지로 저장(`completed` 대신 result). 텔레그램 버튼과 같은 구분이고, 딴짓으로 끝난 세션을 나중에 집계하기 위함. 완료를 고르면 하루 목표도 완료 처리
- 열린 중단이 있으면 세션을 끝낼 수 없음(먼저 종류를 정해야 집중 시간이 확정되므로)
- 하루 목표를 지워도 집중 세션은 기록으로 남기고 연결만 끊는다
- 휴식 타이머는 세션 종료 후 화면에서만 돌고 기록하지 않음. 기본 25/5분, 세션마다 변경(설정 화면은 1-5)

1-3a에서 정한 규칙(2026-10-23):
- WeeklyPlan은 요일 대신 날짜(주간 목표의 주 안)로 저장. 주간 목표를 지우면 계획도 지우고, 계획이 있으면 주간 목표의 주를 바꿀 수 없음(하루 목표와 같은 규칙)
- 주간 계획에서 하루 목표는 자동으로 만들지 않고, 버튼으로 내용을 채운 하루 목표를 만든다
- DailyLog는 날짜당 1개, 컨디션은 1~5(선택). 집중·딴짓·수동 기록 시간과 하루 목표 완료 수는 저장하지 않고 조회할 때 계산
- ManualStudyLog는 분류 필수, 1~600분

1-3b에서 정한 규칙(2026-10-23):
- WeeklyJournal은 주(월요일)당 1개, MonthlyReview는 월당 1개. 없으면 빈 값과 자동 요약을 돌려주고 PUT으로 만들거나 고친다
- 주 요약: 요일별 집중·수동 기록·딴짓 시간, 하루 목표 완료 수, 컨디션 / 월 요약: 그 달에 속한 주(ISO, 목요일 기준)별 같은 합계와 주간 목표 달성 수, 일지 작성 여부
- AI 요약 칸은 2단계에서 채우고 1-3b에서는 저장만 해 둔다(읽기 전용)

1-4a에서 정한 규칙(2026-10-23):
- 집중 구간 = 세션 [시작, 종료(진행 중이면 지금)] − (딴짓·휴식·종류 미정 중단). 딴짓 구간 = DISTRACTION 중단. 각 구간을 서울 기준 시(hour) 경계로 잘라 날짜·시간대에 넣으므로 자정을 넘는 세션도 날짜별로 나뉜다
- 수동 기록은 시간대가 없어 날짜·분류 집계에만 들어가고 히트맵에는 빠진다
- 기간은 최대 731일. 연속 공부일은 기간과 상관없이 to부터 거꾸로(오늘 공부가 없으면 어제부터) 센다
- 기간 목표 시간 = 분류의 주간 목표 시간 × 기간 일수 / 7

- 기간 추이 단위: 오늘·이번 주·직접(31일 이하)은 일별, 이번 달·직접(32~180일)은 주별, 그보다 길면 월별

1-4c에서 정한 규칙(2026-10-23):
- 진행률은 두 가지로 나눠 표기: "주간 목표 n/m 달성"(자동, 막대) / 월간 목표 수치 "현재/목표 단위"(직접 입력). 섞어 계산하지 않음
- 상태 색: 진행 중인 기간에서 경과율 − 진행률 ≥ 20%p면 "위험"(노랑), 그 밖은 "순조"(초록), 달성은 "달성"(파랑), 시작 전·기간 지남은 회색. 경과율은 오늘까지 지난 날 / 기간 일수
- 주간 목표 이어가기: 못 끝낸 주간 목표를 다음 주에 같은 내용·분류로 새로 만들고 원래 목표에 "이어감" 표시(carried_over). 다음 주가 다른 달에 속하면 그 달의 월간 목표를 골라야 함. "그대로 두기"는 아무것도 바꾸지 않음
- 회고 위치(2026-10-23, 시중 서비스 조사 후 사용자 결정 "의식 흐름 안에 둠"): 회고 쓰기는 안내 흐름(주간 계획하기 1단계)과 주말 알림으로 불러내고, 계획 화면에는 평소 접어 둠
  - 주간 일지: 이번 주는 금~일요일에만 펼침, 지난 주는 펼침, 그 외에는 "주간 일지 쓰기" 한 줄. 이미 쓴 일지는 글로 보여주고 [수정]
  - 월간 회고: 그 달 마지막 주(마지막 월요일)부터 펼침, 지난 달은 펼침, 그 외 접음. 쓴 회고는 글로
  - 금~일요일에는 일정 화면에 "이번 주 돌아보기" 배너(이번 주 일지를 썼으면 숨김)
  - 모아 보기: [월]에 그 달 주간 일지 모음, [최종]에 월간 회고 모음. 회고 전용 메뉴는 만들지 않음
- 주간 계획하기 알림: 월요일에는 오늘 화면에 "이번 주 계획하기" 배너(이번 주 닫기 가능), 이번 주 주간 목표가 하나도 없으면 요일과 상관없이 표시

1-4e 계획 vs 실제(2026-10-23, 사용자 결정. Toggl 달력 플래너의 계획/기록 비교, Cal Newport 시간 블록 플래너 참고):
- 이유: 타이머 시작·정지 방식이 불편했음(시작 폼, 화면 이동, 결정 과다). 시간표의 계획 옆에 "그 시간에 실제로 한 일"을 남겨 비교하는 방식으로 바꿈
- 시간표 하루 열을 왼쪽 "계획" 줄(시간 블록)과 오른쪽 "실제" 줄(실제 기록)로 나눔
- 기록 방법: 지난 계획 블록의 [✓ 계획대로](같은 시간·내용 복사) / 실제 줄 빈 칸을 끌어 종류 고르기. 눈금 15분, 시간 칸에 직접 쓰면 5분 단위도 가능. 실제 기록도 계획 블록처럼 끌어 옮기고 아래 끝을 끌어 늘임(사용자 요청), Shift+끌기는 그 위에 새 기록(딴짓 덧붙이기)
- 실제 기록끼리는 겹치지 않음: 새 기록이 들어오면 겹친 기존 기록을 잘라내거나 둘로 나눔(새 기록 우선). 같은 내용이 바로 붙어 있으면 하나로 합침. 하루(00:00~24:00) 안에서만
- 딴짓은 제목만 자유롭게(예: 유튜브, 비워도 됨), 전에 쓴 제목을 자동완성
- 기존 집중 기능: 메뉴·화면·시작 버튼은 없애고 지난 FocusSession 데이터는 보존(지난 날 집계에 포함). 딴생각 메모는 기록 페이지에서 확인
- 계획대로 % = 계획과 같은 일(그 블록에서 만든 기록, 같은 하루 목표, 같은 제목의 일정)을 실제로 한 겹친 분 ÷ 지금까지 지나간 계획 분. 미래 계획은 분모에 넣지 않음
- 하루 마무리 첫 단계 "실제 채우기": 지나갔는데 실제 기록이 하나도 없는 계획 블록마다 [✓ 계획대로] / [일부만](몇 시까지) / [⚠ 딴짓](제목) / [못 했어요](빈 칸으로 둠)
- 비교 표시: 일정 상태줄(실제 공부·계획대로 %), 하루 마무리 결과, 기록 페이지 카드. API `GET /api/actual-logs/compare?date=`, 하루 기록 요약의 `plan`
- 집계(③): 공부 = 실제 기록의 하루 목표·분류 공부 + 수동 기록, 딴짓 = 실제 기록의 딴짓, 기타 일정은 공부에 넣지 않음. 분류는 기록 → 하루 목표 → 주간 목표 순. 실제 기록이 있는 날은 그날 집중 세션을 빼서 두 번 세지 않고, 실제 기록이 없는 지난 날은 집중 세션으로 센다
- 단계: ① 실제 기록 + 시간표 두 줄 → ② 하루 마무리 "실제 채우기"와 비교 표시(계획대로 %, 빗금) → ③ 집계·대시보드를 실제 기록 기준으로 → ④ 집중 기능 화면 정리

1-4f 목표 구조 단순화(2026-10-23, 사용자 결정. Sunsama Weekly Objectives·Things 3 조사):
- 이유: 최종 → 월간 → 주간 → 하루 4단계를 모두 만들어야 오늘 할 일을 적을 수 있었고, 주 보기의 "계획" 카드와 일정의 "하루 목표"가 비슷한데 달라 어디에 적을지 헷갈렸음. Sunsama는 주간 목표 한 단계만 두고 할 일 연결은 선택

- 트리거: 버튼, 하루 기록 저장 시, 일요일 자동, 텔레그램

### 9-2. 시간 배분 인사이트
- 입력: 분류별 시간·비율, 목표 비율, 최종/월간 목표와 남은 기간, 추이, 히트맵
- 예: "면접 2주 전인데 면접 준비 8%(목표 25%)", "사이드 프로젝트가 3주 연속 목표 초과, 코테는 감소 추세", "집중은 오전 9~11시가 최고"
- 제안 적용 시 다음 주 분류별 시간 배분/주간 계획 초안(AiDraft) 생성

### 9-3. 자동 분류
- 목표 내용으로 분류 추천("자소서 첨삭" → 이력서 작성), 미분류 세션 일괄 분류 제안, 승인 후 반영

## 10. 단계
- 1단계: 목표 구조, 오늘/집중 모드, 딴짓 기록, 회고 3종, 분류·수동 기록, 시간 집계 API, 시간 대시보드(차트), 설정, 텔레그램(알림·명령·/stats)
  - 1-0 프로젝트 기본 틀 (완료)
  - 1-1 분류와 목표 구조 (완료): Category, Goal, MonthlyGoal, WeeklyGoal + 목표 트리·캘린더 화면(`/goals`) + 설정의 분류 관리
  - 1-2a 하루 목표 (완료): DailyGoal(핵심 최대 3개, 첫 행동, 분류 상속, 넘기기, 핵심↔추가 전환) + 캘린더 날짜 클릭 패널 + 오늘 화면의 목표 부분
  - 1-2b 시간 블록과 집중 모드 (완료): TimeBlock, FocusSession, Interruption, DistractionNote + 오늘 화면의 시간 블록 + 집중 모드(타이머, 딴짓 버튼, 딴생각 메모, 탭 이탈 감지)
  - 1-2c 시간표 UI 개선: 오늘 화면의 시간 블록 타임라인을 맥 캘린더 일·주 보기처럼 바꿈. 큰 시간표 + [일][주] 전환 + 드래그로 만들기·옮기기·늘이기 + 하루 목표를 끌어다 놓기 + 실제 집중 세션 겹쳐 보기
  - 1-2c 추가(2026-10-23): 밥 먹기·산책처럼 목표가 아닌 일정도 시간표에 넣어야 하루 계획이 실제와 맞음. TimeBlock의 하루 목표를 선택으로 바꾸고, 목표 없는 블록은 제목과 날짜를 직접 받음. 목표 없는 블록은 분류가 없고 공부시간 집계와 무관하며(집계는 집중 세션 기준), 다른 블록과 겹치지 않는 규칙은 똑같이 적용
  - 범위 추가(2026-10-23): 1-4까지 써 보니 오른쪽 좁은 타임라인에서 폼으로 시간을 고르는 방식이 계획 짜기에 불편해서, 1-5 전에 1-2c로 끼워 넣음. 백엔드 규칙(겹침 금지, 하루 목표 날짜 안)은 그대로
  - 1-4c 계획 화면 통합(1-5 전에 진행): `/plan`(줌 [최종][월][주]) + 주간 계획하기 안내 + 주간 목표 이어가기 + 상태 색. 매주 쓰는 흐름이라 1-5보다 먼저(2026-10-23 사용자 결정)
  - 1-4d 일정 화면 정리와 기록 페이지: 알림 한 칸, 가져올 것 구역, 시간 잡음/남은 시간, 하루 마무리 창, `/log` 기록 페이지(+ `GET /api/daily-logs?from=&to=`)
  - 1-3 기록과 회고 (완료): WeeklyPlan(요일별 계획) 포함
    - 1-3a 주간 계획과 하루 기록 (완료): WeeklyPlan, ManualStudyLog, DailyLog + 주간 화면(`/weekly`, 요일별 계획) + 오늘 화면의 하루 기록·수동 공부 기록·오늘 계획
    - 1-3b 주간 일지와 월간 회고 (완료): WeeklyJournal, MonthlyReview + 주간 화면의 일지·요약 + 월간 화면(`/monthly`)
    - 범위 조정(2026-10-23): 1-2와 같은 이유로 1-3을 1-3a/1-3b로 나눔
  - 범위 조정(2026-10-22): DailyGoal은 오늘 화면, WeeklyPlan은 주간 화면과 함께 만들어야 화면에서 바로 확인할 수 있어서 1-1에서 각각 1-2, 1-3으로 옮김
  - 범위 조정(2026-10-22): 1-2가 하루 목표·시간 블록·집중 모드·딴짓 기록까지 포함해 한 번에 확인하기 커서 1-2a/1-2b로 나눔. 1-1 캘린더에서 날짜를 눌러 하루 목표를 넣는 요구를 1-2a에 포함
  - 1-4 시간 집계와 대시보드
    - 1-4a 집계 API와 대시보드 기본 (완료): `/api/stats/summary`, `/by-category`, `/timeseries`, `/heatmap` + 대시보드 상단 카드·기간 선택·분류별 시간 막대
    - 1-4b 차트와 체크리스트: 기간 추이 누적 막대, 히트맵, 집중 vs 딴짓(차트 라이브러리 Recharts) + ChecklistItem과 체크리스트 화면
    - 범위 조정(2026-10-23): 1-2·1-3과 같은 이유로 나눔. API를 1-4a에 모아 집계 규칙을 한 번에 테스트하고, 화면은 숫자 → 차트 순으로 확인
  - 1-4e 계획 vs 실제 (①~④ 구현, 화면 확인 대기): ActualLog + 시간표 두 줄([✓ 계획대로], 실제 줄 끌어 기록), 하루 마무리 실제 채우기, 집계 기준 전환, 집중 화면 정리
  - 1-4f 목표 구조 단순화 (구현, 화면 확인 대기): 주간 목표 연결 선택, 계획 카드를 하루 목표로 합침, 최종 화면 목표 편집 정리, 어려운 정보 줄이기, 1분 미만 –
  - 1-5 설정과 텔레그램 봇
- 2단계: AI(피드백 → 시간 배분 인사이트 → 자동 분류 순) + 자연어 입력
- 3단계(선택): 크롬 확장, 지원 현황 트래커, 서버 배포

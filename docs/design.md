# job-scheduler 설계 (v4, 2026-10-20)

## 1. 개요
- 위치: `/Users/sangwoo/Desktop/github/job-scheduler`
- 목적: 퇴직 후 이직 준비용 개인 도구. "계획이 불명확 → 시작이 어려움 → 딴짓으로 샘" 문제 해결 + 어디에 시간을 썼는지 파악
- 스택: Kotlin Spring Boot(JPA) / React + TypeScript(Vite) / PostgreSQL(Docker Compose), 테스트는 H2
- 로그인 없음(1인용). 텔레그램 봇은 내 chat ID만 허용
- 구조: `backend/`, `frontend/`, `docker-compose.yml`
- 시간대: Asia/Seoul 고정

## 2. 목표 구조
```
최종 목표
 └ 월간 목표 ─────────── 월간 회고
    └ 주간 목표 → 주간 계획 ── 주간 일지 ── AI 주간 피드백
       └ 하루 목표(핵심 3개 + 추가 목록) → 시간 블록 → 집중 세션 → 하루 기록 ── AI 하루 피드백
모든 목표/세션은 활동 분류(Category)를 가짐 → 시간 대시보드로 집계
```
- 아래 단계는 반드시 위 단계에 연결, 진행률 자동 집계
- 못 끝낸 하루 목표는 넘기기/재배치
- 주는 월요일 시작, 월에 걸친 주는 목요일이 속한 달(ISO)

## 3. 엔티티
| 엔티티 | 주요 필드 |
|---|---|
| Goal | 제목, 설명, 시작일, 목표일, 상태 |
| MonthlyGoal | goal, 연월, 내용, 목표/현재 수치(선택), 달성 여부 |
| WeeklyGoal | monthlyGoal, 주 시작일, 내용, category, 달성 여부 |
| WeeklyPlan | weeklyGoal, 요일, 작업 내용 |
| DailyGoal | weeklyGoal, 날짜, 내용, 첫 행동, category(기본: 주간 목표 상속), 유형(CORE/EXTRA), 순서, 상태 |
| TimeBlock | dailyGoal, 날짜, 시작/종료 시간 |
| FocusSession | dailyGoal, category(기본: 하루 목표 상속, 변경 가능), 시작/종료, 설정 집중·휴식 시간, 실제 집중 분, 완료 여부, 시작 경로 |
| Interruption | session, 시작/종료, 유형(딴짓/공부자료/휴식), 감지(탭 이탈/버튼), 메모 |
| ManualStudyLog | 날짜, category, 분, 메모 (책·오프라인 스터디 등 타이머 없이 한 공부) |
| DistractionNote | session, 내용, 확인 여부 |
| DailyLog | 날짜, 메모, 컨디션 (집중/딴짓 시간 자동 집계) |
| WeeklyJournal | 주 시작일, 잘한 점, 아쉬운 점, 다음 주 반영, AI 요약 |
| MonthlyReview | 연월, 회고, 다음 달 방향, AI 요약 |
| Category | 이름, 색상, 순서, 목표 비율(%)·주간 목표 시간(선택), 활성 여부. 기본값: 이력서 작성, 면접 준비, CS 공부, 코딩 테스트, 사이드 프로젝트, 기타 |
| ChecklistItem | category, 내용, 완료 여부 (ChecklistCategory는 Category로 통합) |
| AiFeedback | 범위(DAILY/WEEKLY/MONTHLY), 대상, 입력 스냅샷(JSON), 지표, 잘한 점, 개선점, 제안, 모델명, 생성 시각, 사용자 평가 |
| UserSettings | 기본 집중/휴식(25/5), 알림 시각, 방해 금지 시간, 알림 on/off, 피드백 톤, 자동 피드백 on/off, 하루 목표 공부 시간 |
| AiDraft | 유형, 입력, 생성 결과, 상태(대기/승인/거절) |

규칙: CORE 하루 목표는 최대 3개(강제), EXTRA는 제한 없음.

1-2b에서 정한 규칙(2026-10-22):
- TimeBlock: 하루 목표의 날짜 안(최대 24:00까지)에서만, 같은 날 블록끼리 겹치지 않음. 하루 목표를 삭제하거나 다른 날로 넘기면 그 목표의 블록은 삭제(원래 날의 시간은 다른 날에 의미가 없으므로)
- FocusSession: 하루 목표 없이 분류만 골라 시작할 수 있음(공부 자료 찾기처럼 목표가 애매한 경우). 진행 중 세션은 1개
- 탭 이탈은 30초 이상일 때만 Interruption으로 기록

## 4. 시간 집계 규칙
- 순 공부시간 = 집중 세션 실제 시간 − (딴짓 + 휴식) 중단 시간 + ManualStudyLog
  - 중단 유형 "공부자료"는 공부시간에 포함
  - 휴식 타이머 시간은 제외
- 자정을 넘는 세션은 날짜별로 분할 집계
- 분류 우선순위: 세션 category → 하루 목표 → 주간 목표 → "미분류"
- 미분류 시간은 대시보드에 표시하고 AI 자동 분류 제안
- 1인 사용 규모라 조회 시 SQL 집계. 느려지면 일별 집계 테이블(DailyStat) 추가

## 5. API
- `/api/goals`, `/api/monthly-goals`, `/api/weekly-goals`, `/api/weekly-plans`, `/api/daily-goals`(+넘기기, CORE↔EXTRA), `/api/time-blocks`
- `/api/focus-sessions`(시작/종료, 시간 설정, category 변경), `/interruptions`, `/notes`
- `/api/manual-logs`
- `/api/daily-logs`, `/api/weekly-journals`, `/api/monthly-reviews`
- `/api/categories`, `/api/checklist/items`, `/api/settings`
- `/api/stats/summary?from=&to=` (순 공부시간 합계, 일평균, 딴짓 비율)
- `/api/stats/by-category?from=&to=` (분류별 시간·비율·목표 대비)
- `/api/stats/timeseries?from=&to=&unit=day|week|month` (기간별 추이, 분류별 누적)
- `/api/stats/heatmap?from=&to=` (요일×시간대 집중 분포)
- `/api/ai/drafts` → `/approve`
- `/api/ai/feedback/{daily|weekly|monthly}`, `/{id}/rating`, `/{id}/apply`
- `/api/ai/classify` (미분류 목표/세션 분류 제안 → AiDraft)

## 6. 화면
1. 오늘(메인): 핵심 3개 + 첫 행동 + 시작 버튼, 추가 목록, 시간 블록, 오늘 순 공부시간/목표 게이지
2. 집중 모드: 타이머, 지금 할 일·분류, 딴짓 버튼, 딴생각 메모, 탭 이탈 감지
3. 주간: 목표, 요일별 계획, 캘린더, 주간 일지, AI 주간 피드백
4. 월간: 목표·진행률, 주차별 현황, 월간 회고
5. 최종 목표 대시보드
   - 트리 보기(기본): 최종 → 월간 → 주간 목표와 진행률. 상위 목표와의 연결을 보는 용도
   - 캘린더 보기(트리/캘린더 토글): 월 단위 달력. 주(ISO, 목요일 기준 소속) 한 줄마다 날짜 칸 7개와 그 주의 주간 목표(분류 색 배지, 달성 체크)를 표시하고, 위에 그 달의 월간 목표 진행률을 보여줌. 1-2a부터 날짜를 누르면 그날의 하루 목표 패널이 열림
   - 캘린더를 트리 대신 쓰지 않고 함께 두는 이유(2026-10-22): 1-1 데이터는 월·주 단위라 "왜 하는지"(상위 연결)는 트리가, "언제 하는지"(일정)는 캘린더가 더 잘 보여줌
6. 시간 대시보드
   - 상단 카드: 오늘 순 공부시간 / 이번 주 총합 / 이번 달 총합 / 일평균 / 연속 공부일, 각각 목표 대비와 지난 기간 대비 증감
   - 분류별 비율(가로 누적 막대), 분류별 시간 막대(목표 비율 표시)
   - 기간 추이: 일별(이번 주), 주별(이번 달), 월별(전체) 분류별 누적 막대
   - 집중 히트맵(요일×시간대)
   - 집중 vs 딴짓 비율
   - 기간 선택: 오늘/이번 주/이번 달/전체/직접
   - AI 인사이트 카드
7. 체크리스트
8. 설정: 타이머, 알림, 텔레그램, 피드백 톤, 분류 관리(이름·색·목표 비율), 하루 목표 공부시간

- 알림: 아침, 블록 5분 전, 미시작/이탈, 저녁(하루 피드백 + 오늘 순 공부시간), 일요일(주간 피드백 + 주간 분류 요약), 월말
- `NotificationSender` 인터페이스

## 9. AI (Spring AI ChatClient, 제공자 교체 가능)
- 기능: 목표 분해, 첫 행동 제안, 회고 요약·딴짓 패턴, 다음 기간 목표 추천, 자연어 입력 파싱, 하루/주간/월간 피드백, 자동 분류, 시간 배분 인사이트
- 항상 AiDraft 초안 → 승인 후 저장. 호출은 백엔드에서만

### 9-1. 피드백
- 입력: 서버가 집계한 JSON(계획 vs 실제, 집중·딴짓, 분류별 시간, 목표 연결, 이전 제안 실천 여부)
- 지표는 코드로 계산, LLM은 해석
- 출력: 한 줄 요약, 잘한 점, 개선점(수치 근거), 구체 제안 1~3
- 트리거: 버튼, 하루 기록 저장 시, 일요일 자동, 텔레그램

### 9-2. 시간 배분 인사이트
- 입력: 분류별 시간·비율, 목표 비율, 최종/월간 목표와 남은 기간, 추이, 히트맵
- 예: "면접 2주 전인데 면접 준비 8%(목표 25%)", "사이드 프로젝트가 3주 연속 목표 초과, 코테는 감소 추세", "집중은 오전 9~11시가 최고"
- 제안 적용 시 다음 주 분류별 시간 배분/주간 계획 초안(AiDraft) 생성

### 9-3. 자동 분류
- 목표 내용으로 분류 추천("자소서 첨삭" → 이력서 작성), 미분류 세션 일괄 분류 제안, 승인 후 반영

## 10. 단계
- 1단계: 목표 구조, 오늘/집중 모드, 딴짓 기록, 회고 3종, 분류·수동 기록, 시간 집계 API, 시간 대시보드(차트), 설정, 텔레그램(알림·명령·/stats)
  - 1-0 프로젝트 기본 틀 (완료)
  - 1-1 분류와 목표 구조 (완료): Category, Goal, MonthlyGoal, WeeklyGoal + 목표 트리·캘린더 화면(`/goals`) + 설정의 분류 관리
  - 1-2a 하루 목표 (완료): DailyGoal(핵심 최대 3개, 첫 행동, 분류 상속, 넘기기, 핵심↔추가 전환) + 캘린더 날짜 클릭 패널 + 오늘 화면의 목표 부분
  - 1-2b 시간 블록과 집중 모드: TimeBlock, FocusSession, Interruption, DistractionNote + 오늘 화면의 시간 블록 + 집중 모드(타이머, 딴짓 버튼, 딴생각 메모, 탭 이탈 감지)
  - 1-3 기록과 회고: WeeklyPlan(요일별 계획) 포함
  - 범위 조정(2026-10-22): DailyGoal은 오늘 화면, WeeklyPlan은 주간 화면과 함께 만들어야 화면에서 바로 확인할 수 있어서 1-1에서 각각 1-2, 1-3으로 옮김
  - 범위 조정(2026-10-22): 1-2가 하루 목표·시간 블록·집중 모드·딴짓 기록까지 포함해 한 번에 확인하기 커서 1-2a/1-2b로 나눔. 1-1 캘린더에서 날짜를 눌러 하루 목표를 넣는 요구를 1-2a에 포함
  - 1-4 시간 집계와 대시보드
  - 1-5 설정과 텔레그램 봇
- 2단계: AI(피드백 → 시간 배분 인사이트 → 자동 분류 순) + 자연어 입력
- 3단계(선택): 크롬 확장, 지원 현황 트래커, 서버 배포

일정 화면의 커서(만들기, 옮기기, 늘이기)와 같은 그림체: 보라 #7C5CFF 몸통 + 흰 테두리, 22px. 어두운 배경과 밝은 배경 모두에서 보여요.

누르기

쓰기

막힘
눌러도 안 되는 버튼 (목표 3개일 때 "다시 진행" 등). 시작 설정과 같은 그림

# 회고 작성 버튼에서 네 단계 하루 마무리가 열림

## 증상
회고 페이지의 오늘 회고 쓰기를 누르면 실제 시간 채우기, 오늘 결과, 미완료 이월을 거쳐야 회고 메모를 쓸 수 있었다.

## 원인
일정 화면의 하루 마무리를 위한 DayWrapUp을 회고 작성에도 공통으로 사용했다.

## 해결
회고 페이지에는 DailyReflectionDialog를 연결해 컨디션과 메모를 한 화면에서 작성한다. 기존 일일 기록 조회와 저장 API를 사용하고 일정의 하루 마무리는 유지한다.

## 검증
프론트 빌드, 린트, git diff 검사가 통과했다. 서버 저장 메서드는 메모와 컨디션만 갱신한다. 로그인된 브라우저에서 작성과 수정 화면의 확인은 남아 있다.

## 배운 점
같은 데이터를 저장하더라도 진입 목적에 맞는 작성 흐름을 제공해야 한다.

# Problem analysis result: 툴팁 문제 모음

- 기간: 2026-10-23 ~ 2026-10-24(1-4f, 2-3, 2-4, 2-5)
- 영역: 프론트엔드 CSS(공통 툴팁 `[data-tip]`, 시작 설정 칠하기, 시간표, 목표 아이콘 고르기)
- 공통 툴팁: 요소에 `data-tip="설명"`을 달면 `::after`로 아래쪽에 말풍선을 그린다(`frontend/src/index.css`)

## 공통 원인
툴팁을 `::after`로 요소 안에 그리기 때문에, 그 요소와 조상의 CSS를 그대로 물려받는다.
- **조상의 `overflow: hidden`, 스크롤 영역** → 잘림(1, 4, 7)
- **요소나 조상의 `opacity`** → 같이 흐려짐(2)
- **쌓임 순서(z-index, 그려지는 순서)** → 이웃에게 가림(5, 7)
- **같은 속성 이름의 공통 규칙** → 모양이 섞임(3, 6)

## 배운 점과 앞으로의 규칙
- 툴팁을 다는 요소는 `opacity`로 흐리게 하지 않는다. 흐리게 할 때는 배경색이나 글자색으로 한다.
- 툴팁이 들어가는 묶음(버튼 그룹, 카드 머리)은 `overflow: visible`인지 먼저 본다.
- 툴팁이 이웃에게 가리면 그 요소 전체가 아니라 **마우스를 올린 요소만** z-index를 올린다.
- 모양이 다른 툴팁은 속성 이름부터 나눈다(`data-tip`, `data-past-tip`).
- 이 문제가 계속 생기면 툴팁을 `::after` 대신 화면 맨 위 층(포털)에 그리는 방식으로 바꾸는 것을 검토한다. 지금은 CSS 규칙으로 충분하다.
